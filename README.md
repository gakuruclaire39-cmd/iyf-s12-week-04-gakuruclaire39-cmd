## Project Description
This project is about learning the basics of JavaScript and understanding how it is used in web development. During this week, I worked on different exercises and built two mini-projects: a calculator and a student grade tracker. The activities helped me practise writing code and solving simple problems using JavaScript.

## Technologies Used
- HTML
- JavaScript

## Features
1. Performs basic mathematical calculations.
2. Supports addition, subtraction, multiplication and division.
3. Handles division by zero.
4. Stores student details and their grades.
5. Calculates the average marks of students.
6. Identifies the student with the highest average.
7. Identifies students who need academic improvement.
8. Generates student report cards.

## How to Run
1. Clone the repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Press `F12` to open the browser console.
5. View the JavaScript output in the console.
